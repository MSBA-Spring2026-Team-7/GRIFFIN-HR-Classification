Problem Statement

William & Mary HR is under-resourced for position classification and compensation setting. Over 500+ position descriptions must be classified against Virginia DHRM career groups and pay bands, translated to W&M’s pay scale, and made competitive enough to attract quality applicants.

Manual classification is time-intensive and inconsistent across reviewers. The university needs accurate, transparent, and explainable AI recommendations that augment—not replace—human expertise.

End-to-end batch analytics pipeline — from web scraping Virginia DHRM career group definitions (56 pages: 50 HTML + 6 PDF) through ML training to an interactive Streamlit application. 103 W&M position descriptions processed through a 30+ pattern censoring pipeline to prevent data leakage.

Course tools: H2O AutoML • LangChain • Gemini API • CareerOneStop REST API • BeautifulSoup • SQLAlchemy • Streamlit • SHAP

Machine Learning Results

H2O AutoML trained 80 models via automated machine learning. Best model: Gradient Boosting Machine with learning rate annealing.

  • 5-fold stratified cross-validation
  • 100 training rows (3 unknown-class records dropped)
  • 15 engineered features from position description text
  • Class imbalance: 55 Administrative Services vs. 3–4 smallest classes

Per-class F1: Admin Services 0.79 • Natural Resources 0.82 • Public Safety 0.75 • Trades & Operations 0.71

ML correctly identifies occupational family; correct role typically appears in top 2–3 AI recommendations.

Responsible AI
Public Data Ethics
Rate-limited scraping (1.5s delays), local caching, public government records only
Bias Awareness
Advisory classification with confidence scores; class imbalance documented transparently
Human-in-the-Loop
AI recommends, HR professionals decide; no auto-submission to any system
Data Privacy
30+ pattern censoring removes PII, salary data, classification codes before training

API keys managed via .env — never hardcoded. All credentials excluded from version control.
